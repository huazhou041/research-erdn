Gene correlation explorer

Scope: current RNA-seq reprocessing only (not part of the prev/current comparisons above). For each of the 6 cohorts x 3 subsets (18 combos), genes were ranked by |Pearson r| with the binary recurrence outcome -- the same statistic as the GLM+COR fs_method (cor(gene, recurrence), pairwise-complete) -- and the union of each combo's own top-100 genes forms the 554-gene master list searchable below. Pick a cohort and a gene: the panels are boxplots of that gene's expression split by recurrence status (median line, box = IQR, whiskers, all points overlaid with jitter, dashed marker = mean) across all 3 subsets for the chosen cohort, with a Wilcoxon rank-sum (Mann-Whitney) p-value for the group difference. When the gene is in that specific combo's own top-100, its correlation rank/r is also shown; otherwise it's shown anyway (for cross-subset comparison) with "not top-100 here".

ROC curves

Legends/ranking always use the same per-fold AUC shown in the other tabs -- never a separately-recomputed curve statistic, which can diverge sharply for tiny/imbalanced cohorts and would otherwise rank degenerate configs as "best". A curve drawn mirrored (noted in the legend as "curve shown flipped") means its raw plotted curve was below chance; only the drawing is mirrored, the AUC label never changes. Broad filters cap display and are stratified across subset/datatype/featureset so "All" shows real variety, not just the extremes.

Operating point & optimal cutoff

Pick one ROC curve (from the filters above), then slide the probability cutoff to read sensitivity and specificity at that threshold. The red star marks the Youden-optimal cutoff (maximizes sensitivity + specificity − 1). These are pooled cross-validated predictions, so this is an illustrative operating point, not a validated deployment threshold. Follows the full / ever-smoker toggle.
